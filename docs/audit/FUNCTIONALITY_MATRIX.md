# Матрица функциональности Sentra

Исходное состояние: коммит `54328e4` плюс незакоммиченные правки прошлой сессии (diff сохранён отдельно). Baseline тестов:
65 passed, 7 skipped. Данных кейса (`data/`, `models/`) на машине нет, поэтому сервис запускался на синтетических правилах
`tests/fixtures/rules_mini.json`.

Колонки: **Данные** (откуда берутся), **Природа** (реальные или синтетические), **Действие**, **Backend меняется**,
**Сохраняется**, **После перезапуска**. Столбец «Было» описывает исходное состояние, «Стало» заполнено после доработки.
