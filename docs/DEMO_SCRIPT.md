# Демонстрация Sentra для жюри (5 минут)

Все тексты ниже придуманы для демонстрации, данных кейса в них нет. Скриншоты экранов: `docs/audit/screens/` (их можно переснять командой
`python experiments/draft_audit/make_screens.py`).

## Подготовка (до выхода)

```bash
python scripts/serve.py                  # с данными кейса и моделями; без них: python scripts/serve.py --fixture
```

Откройте `http://localhost:8000/`. Шапка должна показывать «Сервис в работе» (с `--fixture` сервис честно пишет «Режим: только правила»
и предупреждает, что правила тестовые). Нажмите «Новое обращение» (клавиша `N`) и вводите тексты ниже по одному.

**Режим с LLM нужен только для сцены 4:50.** Остальное записывайте без LLM: тогда верны слова «$0 за обращение, без внешних API».
Для сцены про ИИ перезапустите сервис (PowerShell; ключ сохранён в пользовательском окружении как `DEEPSEEK_API_KEY`):

```powershell
$env:COPILOT_LLM_PROVIDER = 'deepseek'
python scripts/serve.py
```

В шапке появится предупреждение «LLM включена: тексты обращений уходят во внешний API». Его не прячьте, это часть честного показа.
Вводите только придуманные фразы, не обращения из valid. Плитка «Задержка p50» учитывает вызов модели (около 1,3 с): запускайте
сцену на свежей базе после нескольких обычных обращений, иначе в кадре будет 1500 мс, а вы говорите про 5 мс.

## Цифры, которые стоит назвать

* Категория (на нашей разметке по `taxonomy.json`): **0,818 accuracy / 0,722 macro-F1 на 627 новых текстах** (0,875 / 0,764 на всех 1000 тикетах valid с учётом 373 повторов из train). Приоритет macro-F1: **0,880** (0,827 на новых текстах).
* Черновик объявлял итог обжалования в 161 из 1000 обращений valid; теперь в 0. «Передано администратору» стояло в 43 из 1000; теперь в 0.
* Запрос видео называет нарушение: ru 35 % → 66 %, uz 0 % → 84 %, а также на казахском (`ойыншыны немесе оның туыстарын балағаттау`).
* Обещаний разбана, возврата и наказания: 0. Несуществующих пунктов: **0 из 1224**. Тесты: **652 из 652** (631 unit + 21 браузерный E2E). Пакетный режим: `make predict IN=tickets.jsonl OUT=predictions.jsonl`.
* Стиль ответов (тире, слеши, эмодзи, разметка, штампы чат-бота) на 1000 обращений valid: в шаблонах было 15 нарушений, стало **0**.
* LLM (DeepSeek, запасной вариант): до неё доходит 16 из 1000 обращений, вызов около 1,2 с и около $0,0005, ответ всегда проверяет человек. На valid автоматизация выросла всего на 1 обращение из 1000: основная масса обращений это жалобы, которые по правилам решает человек.

## Если спросят

* **Почему LLM не отвечает на всё.** Выдуманный пункт обнуляет тикет, лимит p95 5 с и $0,002. Поэтому DeepSeek вызывается только для сомнительных случаев, а её ответ проверяет человек. Локальную Qwen3.5-4B проверили: p95 14,7 с, на kk и uz хуже шаблонов, не включена. EmbeddingGemma 2 пробовали на 15 придуманных запросах: результат обнадёживает, но без независимой разметки не внедряли. Для kk и uz LLM отключена, пока носитель не проверит.
* **Что не проверено.** Казахские и узбекские шаблоны носителем; 60 пар для людей не оценены; метрика жюри нам неизвестна, наши показатели считаем по вердиктам админов.
* **Откуда данные.** Данные кейса в репозиторий не входят (`make check-data`); модели собираются командой `make train`.
