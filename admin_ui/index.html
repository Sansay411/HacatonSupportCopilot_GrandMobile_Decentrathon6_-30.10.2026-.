Новое обращение

Sentra учитывает число файлов и наличие ссылок, но не открывает их и не анализирует изображения. Без ID заявителя дубли не проверяются.

Импорт обращений из JSONL

Одна строка файла: один JSON в формате tickets.jsonl (kind, messages, ticket_id, created_at, reporter_hash). Каждая строка идёт через настоящий триаж. Ответы админов в файле игнорируются, повторный импорт того же файла дублей не создаёт. Битые строки пропускаются и перечисляются с номерами.
